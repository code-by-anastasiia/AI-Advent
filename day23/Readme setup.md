# Командный ассистент для курса AI агентов

Ассистент объединяет:
- **RAG** - поиск в документации проекта
- **MCP** - управление задачами
- **AI** - анализ и рекомендации по приоритизации

## Установка

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Настроить .env файл

Открой `.env` и добавь свой API ключ:

```
ANTHROPIC_API_KEY=sk-ant-...
```

### 3. Запустить Ollama

**Проверь, что Ollama работает:**
```bash
ollama serve
```

**В другом терминале установи модель:**
```bash
ollama pull nomic-embed-text
```

## Запуск

```bash
python main.py
```

## Примеры использования

### Поиск в документации
```
> Что такое RAG?
[находит в architecture.md и объясняет]

> Какие проекты я уже сделала?
[ищет в completed_projects.md]
```

### Управление задачами
```
> Покажи задачи с приоритетом high
[вызывает MCP tool get_tasks(priority="high")]

> Создай задачу: добавить логирование
[вызывает MCP tool create_task()]

> Обновить статус задачи 5 на completed
[вызывает MCP tool update_task_status()]
```

### Анализ и рекомендации
```
> Покажи незавершенные задачи и скажи, с чего начать
[получает задачи через MCP, анализирует, дает рекомендацию]

> Какие задачи связаны с багами?
[фильтрует по тегу "bug"]
```

## Структура проекта

```
team_assistant/
├── knowledge_base/          # Документация
│   ├── README.md           # Обзор курса
│   ├── architecture.md     # Архитектура агентов
│   └── completed_projects.md # Детали проектов
├── tasks.json              # База задач
├── task_server.py          # MCP сервер
├── rag_system.py           # RAG система
├── main.py                 # Главный агент
├── .env                    # API ключи
└── requirements.txt        # Зависимости
```

## Как это работает

1. **Пользователь задает вопрос**
2. **RAG поиск** - ищет релевантные документы (threshold > 0.3)
3. **Системный промпт** - формируется с найденной документацией
4. **Claude анализирует** - нужны ли MCP tools?
   - Если да → вызывает MCP tools (get_tasks, create_task и т.д.)
   - Если нет → отвечает на основе RAG или своих знаний
5. **Финальный ответ** - синтез информации из RAG + MCP

## Логирование

Все логи выводятся в `stderr` для отладки:
- `[RAG]` - работа поиска в документации
- `[MCP]` - вызовы MCP tools
- `[ASSISTANT]` - работа главного агента

## Возможные проблемы

### Ollama не отвечает
```bash
# Проверь, запущен ли Ollama
ollama serve

# Проверь, установлена ли модель
ollama list
```

### API ключ не найден
Проверь `.env` файл - там должен быть твой `ANTHROPIC_API_KEY`

### MCP сервер не запускается
Убедись, что `task_server.py` исполняемый:
```bash
chmod +x task_server.py
```
